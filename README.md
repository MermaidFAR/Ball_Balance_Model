# Ball_Balance_Model

滚球控制系统的机械结构与 CAD 模型仓库。

## 内容

- SolidWorks 零件与总装模型
- STEP / IGES 通用交换模型
- RDK X5、驱动电机、底盘与执行机构相关结构件

## Git LFS

本仓库使用 Git LFS 管理 CAD 二进制文件。首次克隆前请安装 Git LFS：

```bash
git lfs install
git clone https://github.com/MermaidFAR/Ball_Balance_Model.git
```

克隆后可使用以下命令确认大文件已完整下载：

```bash
git lfs pull
git lfs ls-files
```
